# 比赛操作手册

本文适用于本地 GUI 的比赛操作。规则依据和固定棋位编号见 [规则说明](../SPEC.md)，详细界面功能见 [GUI 使用手册](../gui/README-gui.md)。

## 赛前准备

在实际比赛机器上准备好项目、参赛模型文件及搜索配置。`.pt` 权重不随 Git 仓库分发，复制仓库时需另外携带模型。保留本次使用的模型与配置副本，便于赛后核对。

在已安装依赖的环境中，从项目根目录编译并启动：

```bash
conda activate draughts
make interface
PYTHONPATH=interface:. python3 gui/gui.py
```

使用自建环境时省略 Conda 激活步骤。安装说明见 [项目入口](../README.md#安装与启动)。

正式比赛前，在这台机器上用准备好的模型、设备和配置完成一次试运行，确认：

- 棋盘与中文显示正常，鼠标点击及完整吃子路线选择可用。
- 所选模型能够加载，日志中的实际设备符合预期；使用 CUDA 时先确认设备可见。
- 暂停、AI 单步及恢复自动走棋能够完成预期操作。
- 能将 TXT 棋谱保存到预定目录，并打开检查双方名称、走法和结果。

FP16 和编译选项按已经试运行过的设置使用。编译选项可能增加首次推理等待时间；本文不承诺固定加速倍数或首次推理时长。

## 创建比赛对局

1. 打开“新建对局”，按赛事分配设置黑白双方。程序固定黑方先手；旋转棋盘不会交换双方身份。
2. 我方选择使用的 AI 类型。若由操作员录入对手程序的走法，对手方选择“人类”。当前界面没有自动连接对手程序的通信协议。
3. 填写双方棋谱名称。默认“先手方”“后手方”可直接替换为队伍或程序名称。
4. 使用模型 AI 时选择运行设备，双方模型共用该设备；CPU 模式不能启用 FP16。
5. 选择各模型的 `.pt` 文件。MCTS 的可选配置窗口取消后使用默认 `draughts/config/mcts.yaml`。
6. 确认开始，核对初始棋盘：黑方在上方 1–20，白方在下方 31–50。

对局开始后核对日志和当前行棋方，再进行正式走子。关闭“新建对局”窗口会取消本次配置并返回原对局。

## 对局操作

人类方先点击棋子，再点击合法落点。若相同起止点有多条完整吃子路线，在动作列表中核对路径并双击选择；棋谱使用固定的 1–50 编号。

AI 默认可以自动走棋。需要逐步操作时，先暂停，再点击“AI走一步”；完成一步后仍保持暂停。继续自动走棋时使用“继续AI”。

“悔棋”、估值曲线回溯和“重开本局”都会改变当前对局记录。正式对局中如需修正，应按现场裁定操作，并在操作前保存需要保留的棋谱。

## 异常与判负确认

出现非法操作、不可走操作、AI 异常或 AI 返回空/非法走法时，程序弹出判负确认窗口：

| 操作 | 效果 |
|---|---|
| 确定（判负） | 当前行棋方判负，对局结束，棋谱结果记录实际胜方 |
| 取消（重新落子） | 局面和棋谱保持不变，清除选择后重新落子 |
| Escape 或关闭确认窗口 | 等同于取消 |

AI 异常后自动走棋暂停。取消判负后，可以点击“AI走一步”重试，也可恢复自动走棋。是否判负按现场裁定确认。

暂停或切换局面会请求取消搜索。正在进行的单次推理需要结束后才能退出，因此暂停不代表可以立刻中断底层推理。

## 和棋处理

程序尚未实现和棋协商及拒和后的 40 步流程。求和、接受或拒绝、后续计步和优势认定应在现场按规程处理；当前 GUI 也没有将协商和棋结果录入棋谱的功能。

如现场裁定和棋，应按赛事要求另行记录裁定结果。当前对局导出仍会保留程序已有状态，不能将未结束的 `*` 文件直接当作已经录入和棋结果的正式棋谱。

## 保存棋谱

点击棋谱面板下方“导出棋谱”，选择 `.txt` 文件位置。建议按赛事、轮次或对手命名，避免不同对局混淆。

| 结果 | TXT 标记 |
|---|---|
| 先手方胜 | `1-0` |
| 后手方胜 | `0-1` |
| 和棋的格式标记 | `1/2-1/2`；当前 GUI 尚无协商和棋录入功能 |
| 程序中的对局尚未结束 | `*` |

确认判负会写入实际胜方，不增加虚构走法。导出内容对应打开保存窗口时的对局快照；若随后又走棋，应重新导出以保存更新后的记录。

赛后打开文件核对日期、双方名称、最后走法与结果。TXT 采用 UTF-8 BOM、CRLF 换行和完整连跳路径，格式详见 [TXT 棋谱格式](../gui/README-gui.md#txt-棋谱格式)。尚未在所提供说明对应的 Windows 打谱软件中实机导入验证。

当前保存需手动触发，棋谱文件不能直接导入本程序恢复对局。比赛记录以实际保存的文件及现场裁定为准。
