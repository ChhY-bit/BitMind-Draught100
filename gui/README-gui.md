# GUI v0 使用说明

`gui/simple_gui.py` 是当前项目的第一版 Python GUI。它通过 `interface.DraughtsEnv` 调用 C 引擎，不在 GUI 中重新实现棋规。

## 当前功能

- 支持人-人、人-随机AI、随机AI-人、随机AI-随机AI。
- 打开 GUI 时会弹出“新建对局”窗口，用于选择黑方和白方的决策源。
- 显示 10x10 棋盘、棋子和棋位编号。
- 界面文字使用中文，王棋统一用 `K` 标记。
- 棋盘左侧显示棋谱。
- 点击棋子后高亮所有合法落点。
- 点击唯一合法落点时执行动作。
- 如果同一落点对应多条路线，会在侧边栏保留候选动作，用户可双击完整动作执行。
- 侧边栏显示当前行棋方、合法动作数、终局状态、最近一步动作。
- 侧边栏显示完整合法动作列表，可双击动作执行。
- 侧边栏包含彩色日志框，记录选择、执行、警告、错误、终局等事件。
- `新建对局` 按钮可重新选择双方模式。
- `重开本局` 按钮按当前模式重新开始。
- `暂停AI` / `继续AI` 按钮用于控制 AI 自动走棋。
- `AI走一步` 按钮可让当前 AI 方只执行一步。
- 悔棋按钮可撤销最近一步。

## 运行方式

在项目根目录执行：

```bash
make interface
PYTHONPATH=interface python3 gui/simple_gui.py
```

`make interface` 会生成 Python 需要加载的 C 动态库：

```text
build/libdraughts.so
```

## 操作方式

1. 启动后，在“新建对局”窗口中选择黑方和白方的决策源。
2. 如果当前方是人类，点击可走棋子。
3. 棋盘会高亮该棋子的合法落点。
4. 点击高亮落点执行动作。
5. 如果点击落点不能唯一确定动作，请在右侧动作列表中双击具体路线。
6. 如果当前方是随机AI，它会自动从合法动作中随机选择一步。
7. 左侧棋谱会自动记录每一步。
8. 点击 `悔棋` 撤销最近一步。
9. 点击 `新建对局` 可重新选择模式。
10. 点击 `重开本局` 按当前模式重新开始。

## 设计约定

GUI 只负责表现和输入，不负责棋规。

当前动作执行统一走：

```text
action_id -> env.step(action_id) -> C 引擎执行
```

悔棋使用动作历史重放实现：GUI 保存已经执行过的 `action_id`，悔棋时重置 C 环境，并重放除最后一步之外的动作。因此悔棋仍然通过 C 引擎执行规则，不在 GUI 中修改棋盘数组。

这意味着后续可以把人工输入替换为 AI 输入。预期扩展方向：

- 人-AI 模式：一方使用 `HumanPlayer`，另一方使用 AI 决策源。当前随机AI已可用。
- AI-AI 模式：双方都使用 AI 决策源。当前随机AI对随机AI已可用。
- 动作概率显示。
- 棋局记录导出。
- 更适合训练调试的状态可视化。

## 当前限制

- 目前只有随机AI，还没有模型AI。
- 还没有棋局保存/读取。
- 还没有拖拽棋子，当前使用点击选择。
- 王的复杂多路线歧义通过侧边栏动作列表解决。
